# Zametti — бриф для Claude Code, этап 9: тулбар, поиск, экспорт, история v2

## Контекст

Этапы 1–7 закрыты, этап 8 (картинки, JXL) в работе параллельно. Этот этап —
приведение программы к финальному виду: тулбар, единый поиск, экспорт, About,
переделка режима истории, UX-мелочи. Иконки — Lucide (решено), шрифты
IBM Plex в qrc (решено), философия конфига — «только отклонения от дефолтов».

Если этап 8 к моменту работ не влит: кнопка вставки картинок дизейблится
рядом с облаком — интерфейсы не пересекаются больше нигде.

Обязательное чтение: отчёты этапов 4 (поиск), 7 (история), `zametti_todo.md`
(раздел «Тулбар»), `zametti-storage.md`.

## Цель этапа

1. Тулбар с полным набором кнопок (часть — задизейбленные обещания).
2. Единый поиск из правого верхнего угла, включая поиск по истории;
   нижние панели поиска удаляются.
3. Экспорт текущей заметки: `.md` с вложениями и `.pdf`.
4. About: README.md нашим же рендером + таб лицензий.
5. Шестерёнка: комментированный конфиг во внешнем редакторе + перезагрузка
   по watcher-у.
6. История v2: без списка слепков, три кнопки тулбара, челночная навигация.
7. UX-мелочи: «Новая», inline-переименование папки, иконки папок/корзины,
   восстановление курсора, циклические панели.

## Не-цели

- пакетный экспорт (только CLI-утилита, и то не в этом этапе);
- `Ctrl+Shift+H`, regex в поиске;
- содержание в PDF: страница-оглавление отвергнута владельцем («очень
  неудобно»), а настоящих закладок (outline) `QPdfWriter` не отдаёт — в v1
  содержания **нет вовсе**; вернётся, только если появится честный механизм
  PDF-закладок;
- запуск блоков кода, локализация, AppImage — отдельные этапы;
- синхронизация (кнопка облака — задизейбленное обещание).

  о выигрыше.

## Единый поиск (правый верхний угол)

Один виджет на все вызовы: клик по иконке, `Ctrl+F`.
Нижние панели поиска этапа 4 **удаляются**; поведение и навигация
идентичны при любом способе вызова.

- Поле + распахивающийся вниз список: секция «в текущей заметке», черта,
  секция «в остальных»; `F3`/`Shift+F3` циклируют по видимому списку сквозь
  черту; `Esc` закрывает; `Enter` — переход к выделенному;
- замена: раскрытие второго поля, активируются
  «Заменить» / «Найти далее» / «Заменить все» — **только текущая заметка**,
  «Заменить все» — один шаг undo (как в этапе 4);
- **кнопка поиска по истории** (`database-search`): отдельный прогон по всем
  слепкам всех журналов (машинерия сборки из `verify`; на корпусе — секунды,
  прогресс + отмена); результаты — «заметка, дата слепка, фрагмент»; клик →
  режим истории на этом слепке;
- сохраняются все принципы этапа 4: поиск по тексту блоков (не метаданные,
  не разметка), smart case, юникодный фолдинг, вне UI-потока, новый запрос
  отменяет старый, порог 2 символа.

## История v2

Список слепков (таймлайн-панель) **удаляется** — навигация только шагами:
`Ctrl+Z` вглубь (обычно недалеко), `Ctrl+Shift+Z` обратно. Баннер над текстом
и тонировка остаются обязательными — с уходом списка баннер единственный
громкий признак режима, а на громкости держится безопасность проваливания.

В режиме истории на тулбаре активируются три кнопки:

- **Вернуть из истории** (`rotate-ccw-clock`): содержимое слепка становится
  текущим состоянием — той же семантикой этапа 7 (тело; undoable-правка;
  запись `restore`; метаданные живой заметки побеждают);
- **К последней** (`fast-forward`): выход из режима истории к живой версии;
- **Назад к посещённому** (`rewind`): прыжок к последнему посещённому слепку
  этой заметки в этой сессии — закладка для челночных походов «утащил кусок →
  к последней → вставил → назад → утащил следующий». Закладка обновляется при
  каждом уходе из режима истории; живёт в сессии, не в журнале.

**Семантика возврата (вопрос владельца, зафиксировано):** «Вернуть из
истории» — обычная undoable-правка живого буфера, а **запись `restore` в
журнал откладывается до штатного сохранения** (дебаунс / уход из заметки /
Ctrl+S), как у любой правки. Следствия:

- **быстрое раскаяние** — `Ctrl+Z` до того, как сохранение успело сработать:
  буфер снова Tn, сохранение видит прежний хеш → правило «не писать, если не
  изменилось» съедает запись → журнал остался `…, Tn`, **без следа и без
  какого-либо укорачивания**;
- возврат, доживший до сохранения: журнал `…, Tn, Tk`; последующий `Ctrl+Z`
  и сохранение допишут `Tn` → петля `…, Tn, Tk, Tn`. **Укорачивать журнал
  нельзя никогда**: при слиянии журналов устройств объединение записей
  воскресило бы «удалённую», а любое усечение, кроме оборванного хвоста,
  неотличимо от порчи. Петли со временем съедает прореживание — это его
  работа;
- вид записи — `restore` (с временем источника), только если на момент
  сохранения содержимое всё ещё равно слепку; успел поправить — обычный
  `save`;
- воскрешение удалённой заметки (restore после tombstone) — исключение:
  файл материализуется немедленно, откладывать некуда.

Тест обеих ветвей: быстрое раскаяние → журнал байт-в-байт прежний; позднее
раскаяние → петля, число записей строго выросло.

Печатающая клавиша в слепке — по-прежнему не восстанавливает (подсветка
кнопки «Вернуть из истории»).

## Экспорт (одна заметка)

Кнопка/меню → save-as; формат по расширению выбранного имени.

**`.md`**: тело без шапки zametti (она внутренняя), имя файла — из заголовка
с санацией символов ФС; вложения копируются рядом под своими id-именами —
ссылки валидны как есть, фрагменты `#w=` чужие рендереры игнорируют;
**транскодированные JPEG реконструируются в `.jpg` байт-точно** (штатный
режим libjxl), ссылка в экспортированном тексте переписывается на `.jpg`.

**`.pdf`**: **экспортный вариант builder-а** — маркеры, чекбоксы и картинки
у нас рисуются мимо `QTextDocument`, наивный `print()` их потеряет; для
экспорта они кладутся внутрь документа (списки — штатными форматами,
картинки — ресурсами). Секция конфига `export.pdf`:

```
export.pdf.fontFamily / fontSize   переопределение шрифтов (пусто = как в UI)
export.pdf.margins                 поля страницы
export.pdf.imageMaxWidth, imageQuality   пережатие картинок под PDF;
        ширина показа из #w= (пользователь сжал мышкой — это намёк) —
        потолок фактического размера в PDF
```

Содержания нет (см. не-цели). Внешние ссылки обязаны кликаться; внутренние
якоря — проверить и отчитаться честно. Шрифты Plex вшиваются в PDF сами.

## About (справка)

Диалог с табами:

- **README.md** — кладётся ресурсом и рендерится **нашим же ядром и
  builder-ом**, read-only (справка = обычный документ; переиспользование

- **Лицензии** — тексты всех: IBM Plex (OFL), Lucide (ISC), md4c, BLAKE3,

- версия, ссылка на `zametti-storage.md` («данные не заперты»).

## Шестерёнка: конфиг

- Открывает `config.json` во внешнем редакторе (готовый механизм этапа 4);
- при отсутствии файла — генерирует его: **все параметры присутствуют, но
  закомментированы** (`// "editor.fontSize": 13,` со значениями дефолтов) —
  документация и меню для раскомментирования; действующий конфиг остаётся
  разреженным, философия «конфиг = отклонения» не нарушается;
- перед `QJsonDocument` — срезатель `//`-комментариев (и только их, без
  вложенных умностей);
- watcher на файле: изменение → сохранить всё несохранённое (журнал получит
  записи штатно) → **полная перезагрузка UI** (шрифты, цвета, кэши — сброс
  готовым путём этапа 6). Битый JSON → сообщение, работа на прежних
  значениях, никакой перезагрузки на мусор.

## UX-мелочи

- Новая заметка называется **«Новая»** (не «Пустая» — коннотация);
- **создание папки** открывает inline-редактор метки прямо в дереве (та же
  механика — на F2 по папке); Enter — принять, Esc — отмена (пустое имя =
  отмена создания);
- кнопка панелей — **циклично**: скрыть обе левые панели / показать;
  состояние в state;
- **восстановление позиции курсора** при переключении заметок: для
  закэшированных документов уже живёт в кэше — убедиться; для
  некэшированных — позиция в state по id; тест на оба случая.

## Инварианты и тесты

```
A. Поиск существует в одном экземпляре UI: нижних панелей нет, все вызовы
   попадают в угловой виджет с идентичным поведением
B. История: возврат Tk → Ctrl+Z → буфер == Tn; журнал никогда не
   укорачивается (быстрое раскаяние — не растёт вовсе, позднее — петля)
C. Экспорт .md: реконструированные .jpg байт-точны (BLAKE3 == оригинал
   до транскода); тело без шапки парсится ядром без потерь
D. PDF: маркеры, чекбоксы и картинки присутствуют (визуальная приёмка)
```

Тесты: F3 сквозь черту; замена «все» — один undo; поиск по истории находит
текст, которого нет в живых заметках (только в слепке), клик открывает
режим истории; челнок rewind/fast-forward; конфиг — генерация
закомментированного, срезатель, watcher-перезагрузка с несохранёнными
правками, битый JSON; «Новая»; inline-переименование (Enter/Esc/пустое);
курсор — кэш и не-кэш; иконки — Noto Emoji отсутствует в сборке (если
убирали); Xvfb-снимки: тулбар в обычном режиме и в режиме истории (три
кнопки активны), поиск с распахнутым списком, PDF-страница с фото и маркерами.

Критерий глазами: пройти каждую кнопку тулбара; найти фразу локально,
глобально и в истории — попасть кликом; экспортировать заметку с фото в PDF,
открыть в системном просмотрщике — маркеры, фото, ссылка кликается; создать папку и назвать её не отрывая рук; уйти вглубь истории,
утащить два куска челноком; шестерёнка → поправить кегль → сохранение →
UI перезагрузился с новым кеглем.

## Правила работы

- Ничего за пределами репозитория; хранилище владельца — только чтение; тип
  сборки и файлы владельца оставлять как нашёл.
- Широкое окно в матрице UI-тестов; Debug и Release; снимки Xvfb как
  артефакт приёмки.
- Эталонный счётный цикл возле замеров; каждая починка проверяется снятием.
- «Мои ошибки» обязательны. Измерять, а не рассуждать; сомнение — спросить.
