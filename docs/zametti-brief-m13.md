# Zametti — бриф для Claude Code, этап 13: сортировки

## Контекст

Сценарий-мотиватор — дневник: заметки с датами в заголовках («12 августа
2026г», «2026.08.12», «2026年08月12日»), разложенные по папкам лет/месяцев.
Сортировка по имени на таких заголовках не работает (нет ведущих нулей,
словесные месяцы), сортировка по изменению ломается первой же правкой старой
записи — опечатка или ностальгическая фотка телепортируют прошлогодний день
наверх. Единственная стабильная хронология — **дата создания**, и она в шапке
каждой заметки с этапа 1.

Сейчас: две кнопки сортировки на тулбаре (имя / изменение), одно направление,
режим глобальный. Дневниковый шорткат — отдельный будущий этап, НЕ здесь.

## Цель этапа

1. Третий режим — «по дате создания»; **оба направления у всех трёх** режимов.
2. Сортировка — свойство папки: явная пометка в шапке папки, наследование
   вниз, переживает сессии и поедет в синк (это метаданные).
3. Корень («Все заметки») — живой переключатель, не пишущий ничего.

## Не-цели

- дневниковый шорткат и авто-папки лет/месяцев — позже;
- ручной порядок (drag-перестановка заметок) — не существует и не появляется;
- какие-либо диалоги; сброс — пунктом контекстного меню.

## Модель

```
действующая(папка) = её явный sort
                  ?? ближайший явный предок
                  ?? переключатель корня (живое состояние UI)
```

- явная пометка — ключ в шапке папки-заметки: `sort: name-asc | name-desc |
  modified-asc | modified-desc | created-asc | created-desc`;
- средняя колонка показывает поддерево **по действующей сортировке выбранной
  папки** (явные пометки вложенных папок играют, только когда выбирают их
  самих — сортировка это свойство точки обзора);
- левая панель (папки) упорядочивается тем же действующим режимом — панели
  синхронны, как с этапа 4;
- запись пометки — правка шапки папки **штатным конвейером**: undoable,
  журнал папки получает запись, синк-конфликты решатся общими правилами
  заметок. **`modified` папки НЕ поднимается** — организационная правка, как
  перенос (правило этапа 7);
- сброс в default — контекстное меню папки «Сортировать по: умолчанию»
  (удаляет ключ из шапки);
- корень — не файл: его режим живёт переключателем интерфейса, последнее
  состояние запоминается в `state.json` рядом с ширинами панелей. Локально,
  не синхронизируется — у каждого устройства свой вкус по умолчанию.

## UI

Три toggle-кнопки на месте нынешних двух: **A-Z** (`arrow-down-a-z` /
`arrow-up-a-z`), **часы** (`clock-arrow-down` / `clock-arrow-up`), **календарь**
(`calendar-arrow-down` / `calendar-arrow-up`). Клик по неактивной — включить
(направление по умолчанию: имя — по возрастанию, даты — новые сверху); клик
по активной — **переворот направления**, иконка меняется на парную. Тултипы
с полным названием («По дате создания, новые сверху»).

Выбрана папка → клик пишет пометку в её шапку; выбран корень → меняется
только переключатель. Кнопки показывают действующий режим выбранной папки,
если нет своего, то глобальный. Глобальный можно подсвечивать синим,
свой фиолетовым.

В контекстное меню папок добавить подменю 'Сортировать по' с пунктами:

- умолчанию
- имени (A..Z)
- имени (Z..A)
- дате модификации (сначала новые)
- дате модификации (сначала старые)
- дате создания (сначала новые)
- дате создания (сначала старые)  

## Инварианты и тесты

```
A. Смена сортировки в корне не меняет ни одного файла хранилища
   (BLAKE3-хеши до/после — идентичны)
B. Явная пометка папки переживает перезапуск и читается из шапки
C. modified папки не меняется ни пометкой, ни сбросом
```

- наследование: свой → предок → корень (три уровня фикстуры); смена у
  предка не трогает файлы детей;
- переворот направлений всех трёх режимов; иконки парные (снимки);
- дневниковая фикстура: заметки «1 августа», «2 августа», … «12 августа»
  с честными `created` — по created порядок верен при любых заголовках;
  правка старой записи (modified прыгнул) НЕ двигает её в created-режиме;
- сброс контекстным меню удаляет ключ, папка наследует;
- round-trip: пометка → сериализация → parse → та же пометка; неизвестное
  значение ключа из чужих рук → игнор с логом, показ по default (не падать);
- state.json запоминает корневой переключатель между сессиями;
- Xvfb-снимки: три кнопки в обоих направлениях, папка со своей пометкой
  против унаследованной.

Критерий глазами: папка дневника с кривыми именами — по календарю новые
сверху, порядок безупречен; поправить прошлогоднюю запись — она не
шелохнулась; переключить сортировку в корне туда-сюда — хранилище не
изменилось ни байтом; перезапуск — всё как оставил.

## Правила работы

- Ничего за пределами репозитория; хранилище владельца — только чтение;
  тип сборки и файлы владельца оставлять как нашёл.
- Широкое окно в матрице UI-тестов; Debug и Release; снимки Xvfb.
- Каждая починка проверяется снятием — целиком.
- «Мои ошибки» обязательны. Измерять, а не рассуждать; сомнение — спросить.
