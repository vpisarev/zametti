# Этап 1: отчёт

26–27 июля 2026. Один вечер работы.

Технические решения и их обоснование — в [zametti-core-notes.md](zametti-core-notes.md);
здесь только итог: что сделано, чем проверено, что сломалось по дороге.

## Что сделано

**Ядро `zametti-core`** — `markdown → IR → markdown`. Ни одного include из Qt;
проверяется отдельным тестом, а не на слово. md4c 0.5.3 вендорингом.

Главное свойство — идемпотентность:

```
serialize(parse(x)) == x                побайтово, для x в каноническом виде
parse(serialize(parse(x))) == parse(x)  для произвольного x
```

Непредставимое моделью сохраняется дословно в `Block::rawSource`. Терять байты
нельзя ни при каких условиях — это главное ограничение всей конструкции.

**Просмотрщик `app`** — дерево заметок слева, отрисованный документ справа,
конфиг, память сеанса, зум, режим `--check` без дисплея.

| CommonMark | 655 | 42 575 | 21, все — мутации |
| GFM | 672 | 43 680 | 33, все — мутации |

На самих файлах всех трёх корпусов, без мутаций, — ноль провалов.

Падающие входы сводятся к двум вырожденным сюжетам: многострочный встроенный
код, где md4c синтезирует содержимое и не даёт ни одного смещения, и незакрытый
заголовок ссылки, растянутый через пустую строку. Проверено на всех: содержимое
не теряется, второй круг неподвижен.

Корпус реальных заметок оказался слабоват как единственная мера — он писался
людьми и конвертерами, пограничные случаи попадают в него случайно. Примеры из
спецификаций состоят из них целиком, и именно они нашли большую часть дефектов.

## Что сломалось по дороге

Каждый пункт найден замером, а не на глаз.

**Нумерация `1. 2. … 1.`** — ровно то, о чём предупреждал бриф. После вложенного
подсписка на внешнем уровне заводился второй `QTextList`, и счёт начинался
заново. Список теперь помнится на каждый уровень вложенности.

**Чекбокс на полстроки выше текста.** Абстрактные метрики шрифта описывают
кегельную площадку с запасом. Замер по пикселям: верх рамки выше верхушки «i» на
5 px, низ не доходит до хвоста «y» на 4 px. Исправлено переходом на
`tightBoundingRect("iy")` — совпадение стало попиксельным.

**Яркая полоса под чекбоксом в выделении.** Рамка рисовалась ниже
прямоугольника, выданного Qt, а выступ за его пределы выделением не
закрашивается. Решено штатным `AlignMiddle`: прямоугольник сдвигает сам Qt,
рисование целиком остаётся внутри.

**Увеличение эмодзи не работало вовсе.** `QFontMetrics` отвечает за цепочку с
запасными шрифтами и на эмодзи отвечает «глиф есть», так что условие не
срабатывало ни разу. Спрашивать надо `QRawFont` — он описывает одну физическую
гарнитуру.

**Документ открывался прокрученным вниз** — на `TODO 2020.md` это 36220 из
40562, то есть почти конец. После сборки курсор оставался в конце документа.

**Буллет уезжал вверх при увеличении.** Знак «•» центрируется по высоте строчных
своего кегля, и сдвинуть его обратно нечем: у Qt нет смещения базовой линии для
текстового прогона. Буллет теперь рисуется кружком от метрик самой строки и
потому растёт на месте.

**Голые ссылки едва не переписали каждую заметку.** Включение автоссылок само по
себе безобидно, но сериализатор оборачивал `https://x` в угловые скобки. Разбор
опознаёт голыми только три схемы, `www.` и почту, только с настоящим доменом и
только ASCII — каждое из этих условий добавлено по конкретному падающему примеру
спецификации.

## Мои ошибки

**Удалил ваш `config.json`.** В проверках стояло `rm -f ~/.config/zametti/config.json`,
и если файл к тому моменту существовал — он пропал. Дальше проверки шли через
`XDG_CONFIG_HOME` в отдельном каталоге, ваш каталог больше не трогается.

**Поставил бинарь копией.** `cmake --install` кладёт снимок, и правки в коде не
доходили до `zametti` в `PATH`: пересобиралась одна сборка, запускалась другая.
Заменено симлинком, записано в README.

**Перезаписывал конфиг при каждом запуске.** Задумывалось, чтобы после
обновления появлялись новые параметры. На деле выживали только известные ключи:
опечатка вроде `uncheckedColour` молча исчезала из файла, то есть найти её
становилось труднее, а не легче. Сейчас приложение конфиг только читает.

## Расхождения с брифом

Три, все вынужденные — каждое ломало инвариант. Отступ вложенных списков
считается по ширине маркера родителя, а не двумя пробелами. Курсив на стыке со
словом выводится звёздочкой, а не подчёркиванием. `- [X]` и `- [ ]  текст`
приводятся к канону, побайтово они не возвращаются.

Дерево заметок бриф относил к не-целям этапа; сделано по отдельной просьбе.

Подробности и обоснования — в [zametti-core-notes.md](zametti-core-notes.md).
