# Книги: план следующей сессии (после 18b, до пометок)

Записано 06.09.2026 по итогам приёмки 18b владельцем («выглядит очень хорошо»). Пометки
`==…==`/`{>>…<<}` (бывшая 18c) откладываются — с ними можно подождать. Ветка следующей
сессии — `books2` (от `main`, куда влита `books`). Отчёт прошлой сессии —
`docs/zametti-m18b-report.md`, там же долги.

## Задачи владельца

1. **Обложка.** Показывать обложку книги (`cover:` в шапке — id вложения, ставит ввоз fb2;
   в тело не вставляется, решение 18a). Где: в чтении перед первой страницей и/или в карточке
   книги в списке — решить с владельцем при постановке.
2. **Сноска — tooltip при наведении мышью** (сейчас — по клику). В плашке — только текст
   сноски; никаких `n_1` и прочих id из `[^n_1]` (ввоз переименовывает id в `n1…`, а
   в тексте книги ссылка показывает id надстрочно) — показывать номер, а не id.
   Заодно посмотреть, как выглядит сама ссылка в тексте: номер вместо `n_1`.
3. **Цитаты.** Разобраться, какая конструкция fb2 становится `>`-цитатой в markdown
   (сейчас в одну плоскую цитату уходят `epigraph`, `cite`, `poem`, `text-author` — отчёт 18a §3)
   и либо подобрать лучшее соответствие, либо рендерить цитату лучше: курсивом и, возможно,
   чуть другим цветом (у стиля уже есть `quoteColor`).
4. **Заголовки с новой страницы** в режиме чтения: первого уровня — всегда, второго —
   возможно, иногда (по крайней мере при `role: book`). Место — `BookPages` (правило начала
   страницы) и облик по роли.
5. **Переключение режимов.** Последовательности нажатий при переходе на другую книгу или
   другую заметку выглядят нелогично (панели спрятаны в чтении, режим помнится по заметке,
   кнопка Reading, ToC). Разобрать сценарии руками с владельцем и выстроить одну понятную
   логику; матрица переходов — в отчёт 18b («Матрица передачи документа» в плане 18b).

## Не забыть из долгов 18b

Синк `bookmarks.json`; правка имени букмарка в списке; кегль статусной строки
(`ui.statusFontStep`); `headingAbove` по кэшу `outline()`; `NotePanels.All` — одиночная гонка
в полном прогоне.
