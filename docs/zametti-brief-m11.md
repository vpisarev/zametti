# Zametti — бриф для Claude Code, этап 11: блоки кода

## Контекст

Этапы 1–10 закрыты / в работе. Блоки кода в модели: построчные QTextBlock с
ContinuationProperty (этап 5), язык живёт в info-строке IR и сериализуется в
```` ```lang ````. Этот этап — семантический и UX-слой блоков кода: полоска с
языком, копирование, выход из блока, табуляция. Подсветки в этапе НЕТ.

Обязательное чтение: отчёт этапа 5 (представление кода), раздел «Картинки»
отчёта 9 (машинерия бордюра и правило краёв — образец), `zametti_todo.md`.

## Цель этапа

1. Полоска над блоком кода: язык слева, копирование справа.
2. Мгновенное задание языка: inline-редактор с автодополнением из текущей
   заметки.
3. `Ctrl+Enter` — выход из блока кода в параграф после него.
4. Табуляция пробелами до стопа + Tab/Shift+Tab по выделенным строкам.

## Не-цели

- **подсветка синтаксиса** — отложена владельцем (на мелких фрагментах чаще
  вредит; позже — базовая: объявления функций/типов, комментарии, литералы
  для python/swift/c++/ficus). Полоска — фундамент под неё, но краски нет;
- запуск кода (Run), нумерация строк, перенос длинных строк — не трогать;
- кнопка «внешний редактор для одного блока» — дизайн в копилке, кладётся
  отдельным заходом; в полоске пока ТОЛЬКО copy (место справа — резерв);
- валидация имён языков — имена свободные строки (владельцу нужны свои:
  `pf`/`pficus` = псевдо-фикус — подсвечивать в будущем, не компилировать;
  `ficus` = полноценный код). Никаких встроенных списков;
- сохранение языка при конверсии блок↔параграф — известная потеря, принята
  владельцем («штука редкая»); умный механизм — попозже, не здесь.

## Часть 1: полоска

- Резерв высоты у **первого блока кодовой серии** — той же машинерией, что
  бордюр картинок (рисование по геометрии блока); укороченная строка,
  визуально часть блока кода;
- слева — имя языка из info: тёмно-серое на светло-сером, ненавязчиво;
  пусто — если языка нет;
- **полоска — не текст**: каретка в ней не живёт, выделение её не включает;
- справа — иконка copy (Lucide), видима при наведении на блок; клик копирует
  **текст кода с переводами строк, без заборов и без info**; короткое
  подтверждение (мигание иконки). Тот же перекрасочный хелпер, что тулбар.

## Часть 2: язык

- Клик по области языка (или пустому месту слева) → **inline-редактор на
  месте** — та же механика, что переименование папки в дереве: Enter —
  принять, Esc — отмена, пустое имя = убрать язык;
- **автодополнение из текущей заметки**: кандидаты — множество языков
  info-строк этого документа, читается из живого IR; отдельной памяти нет —
  заметка и есть память (решение владельца: «текущая заметка = текущая
  колонка Excel»). Префикс 'p' → серым дописывается 'python' (самый
  недавний по позиции в заметке при нескольких кандидатах), Enter/Tab/→
  принимает, продолжение печати уточняет;
- применение = **правка info через штатный конвейер**: undoable, сериализация
  в ```` ```lang ````, журнал получает запись обычным путём;
- имена — свободные строки (см. не-цели), санация только от пробелов и
  забороломающих символов.

## Часть 3: выход из блока

`Ctrl+Enter` из **любого места** блока кода: закрыть блок и поставить каретку
в новый пустой параграф сразу после него. Это лечит ловушку владельца «блок
кода в конце документа — после него не встать» (родня правила краёв картинок
этапа 9), и работает одинаково в середине документа. Обычный Enter в коде
как был — новая строка кода (пустые строки в коде легитимны, двойного-Enter
как в списках НЕ заводить).

## Часть 4: табуляция

- **Tab в блоке кода вставляет пробелы до следующего стопа**;
  ширина — `editor.codeTabWidth` в конфиге, дефолт 4. Символ TAB больше не
  вставляется;
- **литеральные табы** (из старых файлов) отрисовываются в коде с тем же
  стопом `codeTabWidth` — иначе набранное пробелами и старое табами
  разъедутся визуально;
- **выделено несколько строк (или часть строк) внутри блока**: Tab —
  отступ всех затронутых строк на ширину стопа, Shift+Tab — снятие отступа
  (до ближайшего стопа, не глубже нуля); выделение и каретка выживают;
- Shift+Tab без выделения — снятие отступа текущей строки;
- всё — undoable обычными шагами (одна операция = один шаг);
- вне блоков кода поведение Tab не меняется (списки живут как жили).

## Инварианты и тесты

```
A. Полоска не участвует в тексте: каретка, выделение, поиск её не видят
B. Смена языка — одна undoable-правка; Ctrl+Z возвращает прежний info
C. Copy кладёт в буфер байт-в-байт текст кода (с \n между строками, без
   заборов); вставка обратно в блок кода даёт тот же код
D. Ctrl+Enter никогда не изменяет содержимое блока — только создаёт
   параграф после
```

- полоска: высота первого блока серии, снимки при выделении блока и без;
- язык: ввод/Enter/Esc/пусто; автодополнение — префикс, несколько
  кандидатов, заметка без языков (дополнения нет), `pf` принимается;
  round-trip: смена языка → сериализация → parse → тот же info;
- Ctrl+Enter: блок в конце документа, в середине, каретка в первой/последней
  строке; после — печать идёт параграфом;
- табуляция: вставка до стопа с разных позиций, конфиг 2/4/8; выделение
  целых строк, части строк, Tab/Shift+Tab, «не глубже нуля»; литеральный
  таб рисуется стопом codeTabWidth (снимок); undo по шагам;
- матрица «операция × край блока» по образцу картиночной этапа 9 — написать
  ДО починок: Enter/Backspace/Delete/Ctrl+Enter × первая/последняя строка /
  до/после блока;
- Xvfb-снимки: полоска с языком и без, наведение с иконкой copy,
  inline-редактор с серым дополнением.

Критерий глазами: создать блок в конце заметки, написать код, Ctrl+Enter —
печатается обычный текст; кликнуть на полоску, нажать 'p' — серым дописалось
'python', Enter; выделить три строки, Tab-Tab-Shift+Tab — отступы ходят
предсказуемо; навести, нажать copy, вставить в терминал — код как код.

## Правила работы

- Ничего за пределами репозитория; хранилище владельца — только чтение;
  тип сборки и файлы владельца оставлять как нашёл.
- Широкое окно в матрице UI-тестов; Debug и Release; снимки Xvfb как
  артефакт приёмки.
- Каждая починка проверяется снятием (тест обязан покраснеть); матрица краёв
  пишется до починок, а не после.
- «Мои ошибки» обязательны. Измерять, а не рассуждать; сомнение — спросить.
