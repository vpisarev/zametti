# Zametti — бриф для Claude Code, этап 16: формулы

## Контекст

Разведка закончена вердиктом «брать» (`zametti-microtex-final-report.md` —
обязательное чтение целиком, включая грабли сборки и оговорки): MicroTeX
ветка `openmath` @ `086f4eb` + наш патч из семи правок, 98/98 формул корпуса,
одно оставшееся расхождение с LaTeX (`\iff`), медиана рендера 0.017 мс.
Шрифт выбран владельцем: **Euler Math 0.75** (прямые буквы Цапфа/Кнута,
компактнее конкурентов — прямое преимущество для инлайна), текстовый
компаньон — Latin Modern.

Флип «рендер снаружи / исходник при каретке внутри» и слой объекта готовы
(этап 12). Формулы — их третье воплощение плюс один новый механизм: инлайн.

## Цель этапа

1. Вендоринг MicroTeX по рецепту разведки; шрифт Euler + `.clm2` в ресурсы.
2. Display-формулы (`$$…$$`): дорогой таблиц — флип, слой объекта.
3. Инлайн-формулы (`$…$`): Math-спан + инлайн-объект, по-формульный флип.
4. Кэш битмапов в картиночной LRU + прогревочный рендер.
5. Канон границ `$`; предконтроль битого LaTeX с честной рамкой.

## Не-цели

- SVG-вложения — отложены владельцем совсем; SVG в IR — отвергнут (продукты
  рендера не живут в модели данных);
- редактор формул, палитры символов, номера уравнений, пакеты сверх корпуса
  (chemfig, mhchem…), инлайн-векторная графика;
- смена шрифта в UI (шрифт один, Euler; механика `.clm` позволяет вернуться
  к вопросу позже);
- фоновый рендер — не нужен при 0.017 мс, рендер синхронный.

## Вендоринг

По рецепту разведки, перенести из `~/work/zametti_math` в основной репозиторий:

- `3rdparty/microtex/`: подрезанный `openmath` (только Qt-бэкенд), `update.sh`
  с наложением патча `0001-spacing-and-symbol-classes.patch` (тот же, что
  ветками в `github.com/vpisarev/microtex`); патчи — отдельными файлами,
  вендоренное считать своим кодом (ветка без релизов);
- **грабли сборки из отчёта разведки повторить не дать**: `GRAPHICS_DEBUG=OFF`
  (иначе отладочные рамки поверх формул), `HAVE_AUTO_FONT_FIND=OFF` (иначе
  ложный `find_package(Boost REQUIRED)` при `add_subdirectory`);
- шрифты: `EulerMath-Regular.otf` + сгенерированный `.clm2` в qrc; Latin
  Modern текстовым компаньоном; `fontforge` нужен только при пересборке
  ресурсов (`fetch-fonts.sh` из архивов, не из системного TeX Live —
  переносимость на mac/Windows);
- лицензии MicroTeX (MIT) и шрифтов (OFL) — в таб «Лицензии» окна About;
- зависимостей сверх Qt6::Gui — ноль (проверено разведкой); сторож в CMake.

## Канон

- инлайн: `$…$` по pandoc-правилу границ — открывающий `$` не перед
  пробелом, закрывающий не после пробела и **не перед цифрой** («цена $5 и
  $10» — не математика); `\$` — литеральный доллар;
- display: `$$…$$`, в том числе многострочная блочная форма (в корпусе есть);
- **в файле — литеральный текст всегда**; GitHub рендерит `$`-математику
  сам — канон совпадает с ним, tutorial-ы едут без конверсий;
- формула, перенесённая через строку исходника (`$N \approx M$` — в корпусе
  три таких), — законна; сканер обязан её видеть (урок разведки, тест).

## Display-формулы

Третье воплощение слоя объекта, ничего нового:

- каретка вне → рендер по геометрии с резервом (машинерия таблиц: спрятать
  исходные строки, резерв на последней, `markContentsDirty` при возврате);
  внутри → исходник;
- слой объекта: Enter = править, Ctrl+Enter = абзац после, Del/Backspace —
  целиком, стрелки — выбор с уголками; матрица слоя уже существует —
  добавить воплощение в перебор;
- показ по центру колонки; кегль = основной × `formulas.displayScale` (1.0);
- состояние проверяется на выходе из правки, выход перечитывает заметку —
  как у таблиц.

## Инлайн-формулы

Единственный новый механизм этапа.

- **IR**: инлайн-спан Math с литеральным исходником (вместе с `$`);
- **показ**: штатный механизм инлайн-объектов Qt — `U+FFFC` + свой
  `QTextObjectInterface` (тот же, каким Qt рисует инлайн-картинки): перенос
  строк, выделение и клики приходят бесплатно; объект атомарен — **через
  строку не рвётся, один Backspace съедает формулу целиком** (как картинку);
  рисование — из кэша битмапов цветом пера палитры;
- **ПРОБНИК №1 этапа — базовая линия**: посадить `$\frac{a}{b}$` в строку
  текста, приложить линейку к снимку. Механика: ascent/depth от MicroTeX +
  ручка смещения базовой линии формата Qt 6 — но право на жизнь ей даёт
  снимок, а не документация. Дроби, индексы, `$\sqrt{…}$` — глубина ниже
  базовой обязана совпасть с соседним текстом;
- **флип — по-формульно**, не по-абзацному: каретка входит в диапазон
  формулы (стрелкой — она атомарный символ; двойной клик по отрендеренной →
  каретка в исходник к месту клика) → эта одна формула разворачивается в
  `$…$` текст на месте; каретка ушла → свернулась. Соседние формулы не
  флипаются. Подмены — охраняемые, без шагов истории (машинерия этапа 12);
- **инвариант этапа, после инцидента №15 — святой**: `U+FFFC` не существует
  нигде, кроме живого QTextDocument. Сериализация, копирование, журнал,
  файл — всегда исходник из IR. Фаззер: случайные последовательности
  флипов/правок/копирований → в файле и буфере обмена только `$`-текст,
  BLAKE3 хранилища после сессии показа не изменился;
- кегль = окружающий × `formulas.inlineScale` (1.0) — подстройку x-height
  Эйлера к Plex владелец сделает глазами этим коэффициентом.

## Битый LaTeX

Движок молчалив (7 из 10 сломанных формул дорисовывает огрызком без жалоб) —
контроль наш, до вызова:

- баланс `{}`, парность `\left`/`\right` и `\begin`/`\end`; вырожденный
  результат 0×0 — тоже ошибка;
- ошибка → **рамка «ошибка формулы»** с исходником текстом внутри (родня
  рамки «файл не найден»), никогда не падение и не молчаливый огрызок;
- исключения движка (3 из 10) перехватываются в ту же рамку.

## Кэш и прогрев

- битмап по ключу (исходник, кегль, цвет, dpr) в **существующей картиночной
  LRU** этапа 6 — общий бюджет, общее вытеснение; правка формулы
  инвалидирует один ключ;
- **прогревочный холостой рендер при старте** — 22 мс инициализации движка
  не должны достаться первой формуле пользователя;
- `parse` под мьютексом (0.03 мс, потери нулевые), глобальные сеттеры
  движка — только при остановленных рендерах;
- повторный показ заметки = ноль вызовов движка (счётчик, как у декодов).

## Тёмная тема, PDF, история

- цвет — пером из палитры при рендере, никаких инверсий; снимок
  светлым-по-тёмному обязателен;
- PDF: display и инлайн едут через тот же рендер (renderSlice рисует то же,
  что экран); проверка глазами на странице;
- слепки истории рендерят формулы (каретки там нет — всегда рендер).

## Инварианты и тесты

```
A. U+FFFC никогда не покидает QTextDocument: файл, буфер, журнал — только
   $-исходник; BLAKE3 хранилища после любой сессии показа неизменен
B. Инлайн-формула атомарна: не рвётся по строкам, удаляется целиком
C. Повторный показ = ноль вызовов движка (кэш)
D. Битый LaTeX даёт рамку, не падение и не огрызок
```

- канон: «цена $5 и $10», `\$`, формула через перенос строки, `$$`-блок;
  round-trip всех форм;
- 98/98 корпуса в живой заметке; базовая линия снимком с линейкой;
- флип: вход стрелкой/двойным кликом, выход, соседние формулы неподвижны,
  Ctrl+Z после правки формулы — один шаг;
- выделение через формулу, копия абзаца с формулой → `$`-текст;
- кэш: счётчик рендеров, инвалидация правкой, смена темы = новые ключи;
- слой объекта: воплощение «формула» в существующей матрице;
- Xvfb-снимки: инлайн в строке (базовая линия), display по центру, тёмная
  тема, рамка ошибки, страница PDF с формулами, слепок истории.

Критерий глазами: открыть Typesetting Math — «как в учебнике, только
Эйлером»; напечатать `$x^2$` посреди фразы — сидит на строке как влитая;
испортить формулу — рамка с исходником, поправил — ожила; Ctrl+/− —
масштабируется с текстом без мыла.

## Правила работы

- Ничего за пределами репозитория; хранилище владельца — только чтение;
  тип сборки и файлы владельца оставлять как нашёл.
- Широкое окно в матрице UI-тестов; Debug и Release; снимки Xvfb как
  артефакт приёмки.
- Матрица краёв (инлайн-формула у начала/конца строки/абзаца/документа)
  пишется до починок; каждая починка проверяется снятием — целиком.
- Эталонный счётный цикл возле замеров; «Мои ошибки» обязательны.
- Измерять, а не рассуждать; сомнение — повод спросить, а не додумать.
