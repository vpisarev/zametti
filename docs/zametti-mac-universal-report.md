# Отчёт: универсальный бинарь под macOS, Zametti.app, dmg, шрифты Sans

30.08.2026. Продолжение восстановления переносимой сборки на маке
(предыдущее состояние — `docs/zametti-build-macos.md` первой редакции: один
arm64-бинарь, пол 12.0).

## Сделано

1. **IBM Plex Sans вшит** (Regular, Italic, Bold, BoldItalic, Version 3.201 —
   та же, что у вшитого Sans SemiCondensed): пропорциональный шрифт текста
   заметки по выбору человека и опора вывоза в PDF на машинах без шрифтов.
   qrc + таблица `app/resources.cpp` + `resources/fonts/README.md` с
   перемеренной ценой: +422 947 байт в qrc (порог 30) при 903 464 на диске.
   `Resources.All` зелёный.
2. **Пол системы 13.0** — решение владельца после разбора развилки: Qt 6.10
   объявляет минимумом 13, под 12.0 собирается лишь потому, что пол не
   проверяет; прежний комментарий в zenv.sh («12.0 объявлена поддерживаемой»)
   был фактически неверен и исправлен.
3. **Оснастка сведена к трём скриптам** (решение владельца): `zenv.sh`,
   `build-qt.sh` (qtbase+qtsvg на каждую архитектуру в свой префикс
   `~/ai/work/zdeps-<арх>`), `build-app.sh` (обе половины программы → lipo →
   приёмка → `Zametti.app` ad-hoc → dmg; app остаётся рядом). Старые
   `qtbase-configure.sh`, `build-qtsvg.sh`, `build-zametti.sh` удалены.
4. **Универсальный бинарь собран и принят**: 73 МБ (arm64 34 + x86_64 39),
   оба ломтя с полом 13.0, чужих библиотек снаружи нет, дымовые запуски
   обоих ломтей (`--help`, `--noconfig --dump-config`; x86_64 — под Rosetta),
   плюс полный GUI offscreen со свежим `--config-dir` на обоих ломтях —
   живёт, гаснет по SIGTERM без падения.
5. **Zametti.app + Zametti-0.9.dmg**: `io.zametti.zametti`, версия 0.9,
   иконка из `resources/zametti1024x1024.png` (sips+iconutil на месте),
   `codesign --verify --strict --deep` пройден, `hdiutil verify` пройден,
   `plutil -lint` OK; 35 МБ.

## Мои ошибки

1. **Забыл, что чужая архитектура для Qt — кросс-сборка.** Первый прогон
   x86_64 упал на «You need to set QT_HOST_PATH». Нашёл по логу, починил
   передачей родного префикса; заодно это закрепило порядок «родная
   архитектура первой» в `ZARCHS`. Урок: у Qt свои представления о
   кросс-компиляции, и они срабатывают раньше cmake'овских.
2. **Проверка «чужих библиотек» была написана под тонкий бинарь.** У толстого
   `otool -L` печатает заголовок на каждый ломоть, мой `tail -n +2` срезал
   только первый — и проверка «нашла» чужую библиотеку в собственном
   заголовке. Приёмка упала на ложном срабатывании; отбор переписан на
   «строки с табуляцией». Урок: проверку надо прогонять на том виде данных,
   для которого она написана, — толстый бинарь появился в этом же заходе.
3. **`hdiutil create -fmt`** — ключа не существует, правильно `-format`.
   Написал по памяти, не проверив; поймал только прогон.
4. **`hdiutil create -srcfolder` не работает без права монтирования** —
   песочница агента запрещает `/Volumes`, и упаковка падала «Operation not
   permitted». Честный обход, а не оговорка: makehybrid+convert строят тот же
   UDZO вообще без монтирования. Записано и в скрипте, и в build-доке.
5. **Пустой массив под `set -u` на маковском bash 3.2** — раскрытие
   `"${extra[@]}"` упало бы «unbound variable»; поймал до прогона, но лишь
   потому, что вспомнил про 3.2. В скриптах — форма `${arr[@]+"${arr[@]}"}`
   с комментарием.

## Не сделано / оговорки

* dmg при сдаче не открывался монтированием (песочница агента запрещает
  `/Volumes`) — `hdiutil verify` пройден, содержимое собрано из проверенного
  `.app`; щелчок по dmg руками — за владельцем.
* Developer ID и нотаризация — долг (записан в build-доке): ad-hoc не снимает
  предупреждение Gatekeeper на чужом маке, `spctl` отвечает `rejected`, и для
  ad-hoc это норма.
* Запуск на живой macOS 13 (Ventura) не проверялся — машины нет; пол 13.0
  совпадает с обещанием Qt, дальше — вопрос той же честности, что и у Qt.
