# Цитаты и код

> Цитата — отдельный род блока, а не дословный кусок.
> Продолжение той же цитаты идёт следующей строкой.
>
> Второй абзац той же цитаты отделён строкой с одним маркером.

Соседние цитаты канон сливает в одну: в модели это просто два блока подряд.

> Цитата держит разметку: **жирный**, _курсив_, `код` и [ссылку](/цель).

Встроенный код `fx_copy_ptr` — это спан с флагом `code`, а не дословный абзац.
Разметка внутри него не разбирается: `**не жирный** и _не курсив_`.
Кавычки внутри удлиняют ограничитель: ``a ` b``.

Код с языком хранит его в `Block::info`:

```cpp
int main() { return 0; }
```

```sh
echo привет
```

Забор длиннее, если содержимое само содержит забор:

````
```
вложенный забор
```
````

Блок кода без языка — тот же род, только `info` пуста:

```
просто код
```
