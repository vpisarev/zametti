## Чекбоксы и код

- [ ] не сделано
- [x] сделано
  - [ ] вложенная задача
  - [x] и ещё одна
- обычный пункт рядом

Нумерованный список чекбоксов не образует — там это буквальный текст:

1. [x] текст
2. [X] в верхнем регистре
3. [ ]  с двойным пробелом и **разметкой** следом

Блок кода выражается моделью:

```
просто код

с пустой строкой и # решёткой в начале
```

```
```

Экранирование ставится только там, где без него разбор изменится:

буквальная \*звёздочка\*, а решётка и цитата в середине строки — # и > — нет.

\# зато в начале строки решётку экранировать надо
\> и угловую скобку тоже
1\. и номер с точкой

Обратный слэш C:\\tmp удваивается всегда.

Идентификаторы вроде snake_case_name слэшами не обрастают.
