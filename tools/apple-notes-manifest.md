# Манифест Apple Notes: настоящие даты для миграции

Конвертированные в markdown заметки настоящих дат Apple Notes не содержат —
их mtime это дата конверсии, и без манифеста импорт закодирует её и в id, и в
`created`/`modified` (замерено на корпусе: все 244 файла — «26 июля 2026»).
Id выдаётся один раз и потом не меняется, поэтому **финальная миграция — только
с манифестом**.

Скрипт читает у заметок лишь имена и даты (тела не трогает), поэтому быстрый и
не спотыкается о защищённые паролем заметки.

## Запуск на маке

```sh
osascript -l JavaScript apple-notes-manifest.js --prefix "Apple Notes" > manifest.json
```

- При первом запуске macOS спросит разрешение: «Terminal хочет управлять
  Notes» — разрешить (Настройки → Конфиденциальность → Автоматизация).
- Ход выполнения печатается в stderr (по папке на строку), манифест — в
  stdout, поэтому `> manifest.json` забирает только его.

## Параметры

- `--prefix "Apple Notes"` — приставка к путям папок, ровно как папки лежат в
  конвертированном дереве. В нашем корпусе заметки Apple живут под
  `Apple Notes/`, поэтому префикс обязателен — иначе ключ «папка + заголовок»
  не совпадёт и импорт честно отчитается «манифест без файла» по каждой записи.
- `--default-folder Notes` — папка Apple по умолчанию: её заметки конвертеры
  кладут в корень, без подкаталога, и скрипт отображает её прямо в префикс.
  Если система русская и папка называется «Заметки» — указать её.
- `--skip "Имя"` — не выгружать папку (можно повторять). «Недавно удалённые»
  пропускаются всегда.

## Проверка манифеста

```sh
python3 -m json.tool manifest.json | head        # валидный JSON
python3 -c "import json;print(len(json.load(open('manifest.json'))))"  # число заметок
```

Число должно сходиться с числом заметок в Notes (минус пропущенные папки).

## Миграция

```sh
zametti-store import --root <новое-хранилище> --from <конвертированное-дерево> \
    --apple-manifest manifest.json
zametti-store verify --root <новое-хранилище>
```

В отчёте (`<root>.import-report.txt`) смотреть:

- `манифест без файла: …` — запись есть в Notes, файла в дереве нет
  (переименована после экспорта, не экспортирована, лежит в другой папке);
- `времена из файловой системы: …` — файл есть, а записи манифеста к нему не
  нашлось: такая заметка получит дату конверсии, а не настоящую;
- `манифест неоднозначен …` — две записи с одинаковыми «папка + заголовок»
  (в Notes легальны заметки-тёзки в одной папке) — такие пары разбирать руками.

Сопоставление идёт по ключу «папка + заголовок», поэтому манифест надо снимать
с того же состояния Notes, с которого делался экспорт в markdown: между
экспортом и манифестом заметки не переименовывать и не перекладывать.

Источник импорт не меняет никогда; неудачную миграцию можно просто стереть и
повторить с поправленным манифестом.
